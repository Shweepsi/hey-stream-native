# Contributing to Hey Stream

Thanks for your interest! Issues and pull requests are welcome in **English or
French**. The project docs (`docs/`) and commit messages are in French; you
don't need to write French, a maintainer will help.

## How the project is run

- **Scope is fixed for v1.** [`docs/SPEC_V1.md`](docs/SPEC_V1.md) lists what the
  first version does, and nothing else. Work to do is in
  [`docs/TODO.md`](docs/TODO.md) and in issues labelled **good first issue** or
  **help wanted**.
- **New features**: open a Discussion or an issue first, so we can agree before
  you write code. The maintainer decides what goes in.
- Read [`docs/DECISIONS.md`](docs/DECISIONS.md) for the choices already made,
  and [`docs/DESIGN.md`](docs/DESIGN.md) before touching the UI.

## Ground rules

- **All logic goes in `core/` (Rust).** Native UIs only display. The core
  returns error types, never user-facing text.
- **The core is tolerant**: one unreadable entry from a provider is skipped,
  never fatal for a whole list.
- **Never call a real provider** from tests, CI or scripts. Use the mocks
  (wiremock in Rust, MockWebServer on Android). You don't need a subscription
  to contribute.
- **Never log credentials or stream URLs.**
- **No code, images or text from IPTV Smarters** or any other proprietary app,
  and no decompiling.
- **Version**: a PR that changes the app bumps `[workspace.package] version` in
  the root `Cargo.toml` and adds an entry at the top of `CHANGELOG.md`
  (a maintainer can do it for you).

## Before opening a pull request

```sh
cargo fmt --check
cargo clippy --all-targets -- -D warnings
cargo test
cd android && ./gradlew :app:testDebugUnitTest :app:assembleRelease
```

Keep PRs small and focused. Describe the user-visible change, how you tested
it, and on which device if it touches the UI or playback. CI must be green.

## Where help is most wanted

- **Rust core**: performance (streaming JSON parsing, full-text search),
  benchmarks.
- **Android / Compose**: TV focus handling, Media3 playback, accessibility.
- **Apple (SwiftUI + AVPlayer)**: the iPhone, iPad and Apple TV app does not
  exist yet; the Swift bindings are generated by `scripts/bindings.sh`.
- **Testing and translations**: try test APKs on other Android TV boxes and
  report what works; translate `android/app/src/main/res/values*/strings*.xml`.

## Reporting a bug

Use the bug template. Include the app version (Settings › About), the device
and Android version. Never paste your server address, username, password or a
stream link.
